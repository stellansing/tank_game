## 游戏简介

本项目使用 Pygame 实现了一款完整的坦克大战游戏。玩家控制坦克在关卡中与敌方坦克战斗，保护己方基地不被摧毁，击败所有敌人即可过关。

游戏采用**模块化架构**，核心玩法完整可玩，并支持通过 UDP 协议进行双人联机对战。

---

## 功能特性

### 单人模式
- **关卡自动推进**：胜利后自动加载下一关，全部通关后返回主菜单
- **击杀统计**：每关结束显示击杀数量
- **游戏记录**：自动保存每局的胜负与击杀数据

### 联网模式
- **UDP 双人联机**：基于 Host-Client 架构，Host 为权威服务器
- **状态同步**：全量快照同步，Client 纯渲染，保证一致性
- **队友协作**：Host 控制 P1，Client 控制 P2，共同对抗敌人
- **关卡同步**：Host 胜利后自动推进关卡并同步给 Client

### 通用功能
- **用户系统**：登录 / 自动注册，用户名与密码验证
- **信息面板**：实时显示剩余敌人数、生命值
- **音效系统**：爆炸、射击、命中、游戏开始等音效
- **视觉效果**：坦克行走动画、爆炸动画、冰面滑行效果
- **基地保卫**：Home 被摧毁即判负

## 技术架构

### 整体架构

```
┌──────────────┐
│   main.py    │  入口：初始化 → 登录 → 主菜单
└──────┬───────┘
       │
       ▼
┌─────────────────────────────────────────┐
│            模块化游戏引擎                 │
│  ┌─────────┐ ┌──────────┐ ┌──────────┐  │
│  │ 实体层   │ │ 工具层    │ │ 网络层   │  │
│  │ Tank     │ │ Explode  │ │ Host     │  │
│  │ Bullet   │ │ Time     │ │ Client   │  │
│  │ Scenes   │ │ Music    │ │ Protocol │  │
│  └─────────┘ └──────────┘ └──────────┘  │
│  ┌──────────────────────────────────────┐│
│  │       LoadGame.py (核心引擎)         ││
│  │  MainGame  │  MultiplayerGame       ││
│  └──────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

### 联机架构

采用 **Host 权威服务器 + Client 纯渲染端** 的 UDP 双人联机架构：

- **Host**：运行完整游戏逻辑，全量状态同步
- **Client**：仅接收状态快照渲染画面，不运行游戏逻辑
- **同步频率**：每30fps同步一次全量快照
- **输入传输**：Client 将按键操作发送给 Host，Host 代为执行

## 快速开始

### 环境要求

- Python 3.8+
- Pygame 2.6+

### 安装依赖

```bash
pip install pygame
```

### 启动游戏

```bash
python main.py
```

### 运行流程

1. **登录界面**：输入用户名和密码（新用户自动注册）
2. **主菜单**：选择「单人游戏」或「多人游戏」
3. **单人模式**：选择关卡 → 开始战斗
4. **多人模式**：创建房间 / 加入房间 → 联机对战

## 游戏内容

### 地图元素

| 元素 | 图标标识 | 说明 |
|------|---------|------|
| 空地 | `S` | 可通行 |
| 砖墙 | `B` | 可被子弹摧毁 |
| 钢墙 | `I` | 不可摧毁 |
| 河流 | `R` | 不可通行（坦克无法通过） |
| 冰面 | `C` | 降低摩擦力，产生滑行效果 |
| 树木 | `T` | 可通行，视觉遮挡 |


### 胜利 / 失败条件

- **胜利**：消灭关卡中所有敌方坦克
- **失败**：玩家生命值为 0 **或** 基地（Home）被敌方子弹摧毁

### 网络模块

| 文件 | 功能 |
|------|------|
| `UDPSocket` | UDP 套接字封装：绑定、发送、接收（非阻塞） |
| `protocol.py` | 协议定义：消息类型枚举、数据结构、JSON 编解码 |
| `host.py` | `HostNetwork`：主机端连接管理、状态同步、输入接收 |
| `client.py` | `ClientNetwork`：客户端连接管理、输入发送、状态接收 |

### 网络协议 (`protocol.py`)

| 消息类型 | 方向 | 说明 |
|---------|------|------|
| `CONNECT` | Client → Host | 连接请求 |
| `CONNECT_ACK` | Host → Client | 连接确认 |
| `INPUT` | Client → Host | 玩家按键输入 |
| `STATE` | Host → Client | 全量游戏状态快照 |
| `LEVEL_DATA` | Host → Client | 关卡数据 |
| `GAME_START` | Host → Client | 游戏开始通知 |
| `GAME_OVER` | Host → Client | 游戏结束通知 |
| `DISCONNECT` | 双向 | 断开连接 |

### 工具模块

| 文件 | 功能 |
|------|------|
| `explode.py` | `Explode`（坦克爆炸动画，6帧）和 `BulletExplode`（子弹爆炸动画，3帧） |
| `music.py` | `Music`（背景音乐）和 `Sound`（音效）播放器 |
| `sound_manager.py` | `SoundManager`：爆炸、命中、开始三种音效的管理 |
| `time.py` | `TimeComputer`：基于 Pygame tick 的时间间隔计算器 |

## 联机模式

### 建立连接流程

```
Host:  监听端口 → 等待客户端 → 发送关卡数据 → 发送GAME_START → 游戏循环
                                                                       │
Client: 输入Host IP → 发送CONNECT → 接收CONNECT_ACK → 接收关卡数据 ──┘
                                                                    ↓
                                                             接收STATE快照
                                                             发送INPUT
                                                             渲染画面
```

### 数据同步机制

- **Host 权威**：所有游戏逻辑仅在 Host 端运行
- **全量快照**：每 2 帧发送一次完整游戏状态
- **一次性消费**：Client 发送的 InputData 被 Host 消费后立即置空，避免重复处理
- **输入限频**：Client 每秒最多发送 60 次按键数据

### 网络配置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 端口 | 5555 | UDP 通信端口 |
| 缓冲区 | 65536 字节 | UDP 接收缓冲区 |
| 同步间隔 | 33ms | 状态同步间隔 |
| 连接超时 | 10 秒 | 连接超时时间 |
| 接受超时 | 60 秒 | 等待客户端超时 |

## 数据存储

所有数据以 JSON 格式存储在 `data/` 目录下：

- **users.json**：用户账号数据（用户名 → 密码映射）
- **records.json**：游戏记录（每个用户的历史记录列表）

### 记录格式

```json
{
  "用户名": [
    {
      "timestamp": "2024-01-01 12:00:00",
      "level": 3,
      "result": "win",
      "kills": 12,
      "is_multiplayer": false
    }
  ]
}
```

## 关卡配置

关卡文件存储在 `modules/levels/` 目录下，格式为 `.lvl` 文本文件：

### 文件格式

```
%TOTALENEMYNUM:20       # 本关敌人总数
%MAXENEMYNUM:6          # 同时在场最大敌人数量
%HOMEPOS:12,24          # 基地位置（网格坐标）
%HOMEAROUNDPOS:...      # 基地周围砖块位置
%PLAYERTANKPOS:...      # 玩家坦克出生位置
%ENEMYTANKPOS:...       # 敌方坦克出生位置

# 地图网格（26×26，S=空地 B=砖墙 I=钢墙 R=河流 C=冰面 T=树木）
S S B B S S ...
```

## 开发说明

### 代码规范

- 遵循 PEP8 编码规范
- 注释使用英文，关键逻辑添加中文说明
- 命名采用 `snake_case` 风格
- 类名使用 `PascalCase`

### 图片资源

- 坦克图片采用**帧切割方式**：4 方向 × 2 帧动画，排列在单张图片中
- 所有图片通过 `globalCache.py` 全局缓存，避免重复加载
